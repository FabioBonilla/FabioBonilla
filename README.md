### 🚀 Proyectos Destacados

#### 🏦 [NovaBank](https://github.com/FabioBonilla/novabank)
> Aplicación bancaria simulada full-stack diseñada como pieza central de portafolio backend.
* **Aspectos clave:** Manejo monetario exacto con `BigDecimal`, transferencias atómicas protegidas con `@Transactional` (rollback automático) y control de concurrencia con bloqueo optimista (`@Version`). Preparada para despliegue en GCP.
* **Tecnologías:** `Java 21` • `Spring Boot` • `PostgreSQL` • `Docker` • `GCP`

---

#### 📈 [Manufacturing OEE & SPC Dashboard](https://github.com/FabioBonilla/manufacturing-oee-dashboard)
> Aplicación web interactiva para monitorear la Eficiencia Global de Equipos (OEE) y Control Estadístico de Procesos (SPC).
* **Aspectos clave:** Incluye gráficos de control X-Bar, análisis de capacidad de procesos (Cp, Cpk), diagramas de Pareto para defectos y exportación de reportes automatizados a Excel.
* **Tecnologías:** `Python` • `Streamlit` • `Plotly` • `Pandas` • `OpenPyXL`

---

#### 🏭 [Manufacturing KPI Dashboard](https://github.com/FabioBonilla/manufacturing-kpi-dashboard)
> Plataforma de analítica diseñada para visualizar indicadores clave de producción e industrial performance.
* **Aspectos clave:** Monitoreo de calidad, análisis de tiempos muertos (*downtime*) y tasas de desperdicio (*scrap rate*) mediante reportes estadísticos e interfaces interactivas.
* **Tecnologías:** `Python` • `Pandas` • `Matplotlib` • `Seaborn`
