### 🚀 Proyectos Destacados

* **[NovaBank](https://github.com/FabioBonilla/novabank)** — Aplicación bancaria simulada full-stack diseñada como pieza central de portafolio backend. Destaca por su manejo monetario exacto con `BigDecimal`, transferencias atómicas protegidas con `@Transactional` (rollback automático) y control de concurrencia con bloqueo optimista (`@Version`), preparada para despliegue en **GCP**.
  <br>
  <code>Java 21</code> <code>Spring Boot</code> <code>PostgreSQL</code> <code>Docker</code> <code>GCP</code>

* **[Manufacturing OEE & SPC Dashboard](https://github.com/FabioBonilla/manufacturing-oee-dashboard)** — Aplicación web interactiva para monitorear la eficiencia global de equipos (OEE) y control estadístico de procesos (SPC). Incluye gráficos de control X-Bar, análisis de capacidad de procesos (Cp, Cpk), análisis de defectos mediante diagramas de Pareto y exportación automatizada a reportes en Excel.
  <br>
  <code>Python</code> <code>Streamlit</code> <code>Plotly</code> <code>Pandas</code> <code>OpenPyXL</code>

* **[Manufacturing KPI Dashboard](https://github.com/FabioBonilla/manufacturing-kpi-dashboard)** — Proyecto de analítica diseñado para visualizar indicadores clave de producción, rendimiento de calidad, análisis de tiempos muertos (downtime) y tasas de desperdicio (scrap rate) mediante reportes estadísticos e interfaces interactivas.
  <br>
  <code>Python</code> <code>Pandas</code> <code>Matplotlib</code> <code>Seaborn</code>
